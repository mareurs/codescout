## Rules that bite (learned)
- Per-task reviews run no suite: run `scripts/with-slot.sh cargo test --lib no_librarian_production_read_bypasses_the_read_door` when a task adds `OpenOptions`/`fs::read`/`File::open` under `src/librarian/`, and `scripts/with-slot.sh cargo test --test result_caps` when it adds a constant named like a cap (needs `// cap-class: NOT_A_CAP — <reason>`).
- Commit on the shared checkout by pathspec with `-m` before `--`; read `git diff --cached --name-only` first (peers stage paths there; the main checkout holds many). `git branch -d` refuses a branch `experiments` does not hold; `-D` after `is-ancestor` of integration, with the harness `@ack`.
- Find a branch owner by the `Session-Id` trailer on its commits.
- In a worktree session `doc(...)` writes need `workspace=` pinned to the tree: verified 2026-11-15 that an update by id of a document catalogued under the MAIN path still wrote to the worktree file with `workspace=` pinned (main stayed clean). An `@ack_` the tool offers writes to the MAIN repo: do not take it for a worktree write. `memory(...)` takes `workspace=` too: pin the main checkout to write main's store.
- `EnterWorktree` branches from `origin/<default>`, not from the integration branch: create the worktree with `git worktree add <path> -b <branch> <integration branch>` first, then `EnterWorktree` with `path`.
- Message time labels: read `date -u`; do not estimate. A peer-session name changes after compaction; the SID does not.
- `./scripts/fmt-mine.sh` refuses lifecycle files; use `rustfmt --edition 2021 <file>`.
- Never run a Unix-only fixture on the Windows lanes (`#[cfg(unix)]`).

## Causal boundary

Supported: intervention was delivered, actual effort configs differed, contract increased pre-edit reproduction on NU versus low, xhigh added probes/verification, yet none of the NU actors exercised a mixed success/error boundary. No budget/lifecycle early stop or known failed command passed off as a repaired-tree test was found in this six-arm population.

Inference: the bottleneck in this pilot is choosing a discriminating legitimate boundary, not merely asking for more tests or spending more effort. This is a process diagnosis on these six completed development attempts, not a general efficacy estimate or a model-psychology claim. The stronger wording `actors ignored an existing visible mixed test` would be unsupported and should not be used.

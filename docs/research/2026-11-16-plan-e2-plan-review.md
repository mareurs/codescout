## Claims verified (no finding)

- **Schema.** The v1 tables are exactly eight (`schema.rs:40-117`). `open` applies the schema at version 0, refuses a newer file with `SQLITE_SCHEMA`, and refuses a version-0 file that holds tables; a current file is left alone (`:168-225`). The rebuild drops only `derived.db` tables. The old catalog and `vector-cache.db` are other files, so nothing non-derivable is lost.
- **`dump_all`** lists every table from `sqlite_master` except `parse_cache` (`:245-285`), so the equality tests cover the new tables. The banned clock words do not occur in the new column names.
- **Shadow diff.** `diff.rs:902` names its columns, so E2-R14 holds. The edge insert names its columns (`build.rs:613`).
- **Parse cache.** No production caller of `incremental::update`. `cutover build` and `derive-shadow` call `build_full`, which never reads the cache (`cutover.rs:607-609`, `derive_shadow.rs:221-223`). The digest hashes `PARSER_VERSION` and every stored part (`incremental.rs:1425-1450`).
- **Event sections** (`event_text.rs:303-319`). Any `###` section followed by an event comment counts. A section ends at the next heading of level ≤ 3. `body_line_offset(doc, body_lenient(doc))` gives the right offset, 0 when the frontmatter does not parse.
- **E2-R5.** The test `one_document_holds_events_and_relation_lines_in_turn` does write a real `**Mutates:**` relation under `## Relations` (`link_text.rs`).
- **Labels.** The regex `^\*\*([A-Z][A-Za-z ]*[a-z]):\*\*` (`relations.rs:51-56`) admits no `-`, `_`, digit, non-ASCII letter or empty label. `rel_of_label` therefore inverts `label_for_rel`, and the `depends-on` / `depends_on` collision exists only on the rel side, as bug `84e6e61e03beace6` describes. `[[two words]]` is malformed (`grammar.rs:461`).
- **Entry documents.** `parse_entry(&Frontmatter) -> Result<EntryMeta, Vec<EntryError>>` (`entry.rs:104`). `fields` is every `extra` key except the six reserved keys, and typed fields never reach `extra` (`frontmatter.rs:14-40`).
- **Sidecar reads.** `blob_text` returns `Ok(None)` when the file is absent and an error for a link or a non-UTF-8 file (`scan.rs:56-110`).
- **git2 / libgit2.** git2 0.20.4 with libgit2 1.9.2 has `StatusOptions` (`pathspec`, `include_untracked`, `recurse_untracked_dirs`, `include_ignored`, `exclude_submodules`), `Status::CONFLICTED` and `is_shallow`.
- **Read door.** `ReadDoor::bytes`, `ReadError::Io` and `for_project` exist (`read_door.rs:61-67, 138, 386`). The gate's tokens do not include `symlink_metadata`.
- **Gates.** The E1-R9 tripwire is at `tests/inline_gates.rs:705`. `TOOL_SURFACE_CHAR_BUDGET` is 57_664 (`server.rs:6625`).
- **Measurements.** First-parent commits 8,111, all commits 9,822, merges 201. `git log --first-parent -M --name-status -- '*.md'` takes 0.684 s. `git status --porcelain --untracked-files=all -- '*.md'` in the main checkout takes 24 ms and lists 508 paths (`GIT_OPTIONAL_LOCKS=0`).
- **Walk correctness.** Without break-rewrites, the target of a rename is absent from the parent tree and its source is absent from the child tree. Processing additions before renames is therefore enough, and the mutation in `a_rename_onto_a_freed_path_keeps_both_histories` checks the one order that matters.

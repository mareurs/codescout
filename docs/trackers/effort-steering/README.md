## Caveats that constrain interpretation

| Caveat | What is established / what remains open |
|---|---|
| **Onboarding is not tool readiness.** | Empty configured languages hide LSP tools. The fixed-process control reproduced 18→21 tools after programmatic onboarding and verified real navigation. All six audited historical root configurations contained Rust and matched launch hashes; that does **not** prove every old active scope or live LSP call worked. Before each admitted prepared version, verify root/languages, complete actual MCP inventory, successful LSP canaries, native index coverage and a source-bound semantic result. [Evidence](reports/2026-11-09-onboarding-readiness-audit.md). |
| **Files on disk are not delivered instructions.** | Project/global CLAUDE.md, authored Codescout guidance and Recon must reach the actual evaluated CLI. Onboarding metadata, settings files and a scripted backend's boolean cannot establish that. Qualify effective context and loaded tools/skills in the exact pinned client/runtime for all relevant arms. [Context investigation](reports/2026-11-04-worker-context-verification.md), [related issues](issues.md). |
| **Same small score is not equivalence.** | A repeated 1/2 result on two tasks does not establish parity, identify a winning mechanism or support a population-level savings claim. Compare paired task outcomes and complete costs on outcome-blind new tasks; reserve independent held-out validation. [Diagnosis](reports/2026-11-07-semantic-contract-diagnosis.md). |
| **An oracle author is not a repair workflow.** | Cheap test-authoring calls and extra probes did not reliably reject a known wrong repair. Their cost is not the cost of a complete repair. Measure repair acceptance and the entire author/continuation/verification workflow separately.

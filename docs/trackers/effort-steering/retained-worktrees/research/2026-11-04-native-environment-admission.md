Starting LSP processes, session buffers, locks, PIDs and live SQLite/WAL state are not reusable knowledge. Stop all writers before snapshot capture; export only an explicit allowlist of consistent portable artifacts. Give each arm its own writable copy. Do not copy the host .codescout tree or all historical memories wholesale.

### Identity and invalidation

Record stable repository identity plus source-baseline provenance, the source files each knowledge artifact depends on, artifact hashes, onboarding schema/version, exact global/project instructions, generation prompt/model/settings, Codescout/tool versions and actual generation cost. A baseline commit is provenance, not a blanket cache-invalidating key: compare relevant file/content hashes before deciding what to regenerate. When dependencies are uncertain, inspect the changed scope and widen the refresh; do not silently accept stale knowledge.

Keep immutable older snapshots. A historical task may use only knowledge supported by its allowed baseline; a newer onboarding summary can contain future fixes even if it never names the task. Update from baseline source before showing the task issue or any solution/oracle/outcome evidence. The current operator conversation and prior C/D histories must not become author inputs to the common project knowledge. No claim of contamination-free reuse is made before source/provenance and cross-arm access checks.

Two change cases: additional low/xhigh repetitions on the same baseline consume the same snapshot with zero new onboarding generation; a build-command or architecture change updates only dependent memories and prompt, while preserving unaffected artifacts. A rules/template-only change refreshes the prompt without re-exploring the repository. Model changes preserve factual artifacts, with generator provenance retained, unless onboarding generation itself becomes the experimental variable.

### Accounting and next acceptance checks

Record shared setup generation once as S, incremental refresh charges as U, and attempt costs as C_i. Actual campaign spend is S + U + sum(C_i), with all paid setup/repair calls included. Show marginal attempt cost separately; an amortized view allocates shared cost over the actual uses of that artifact, names the denominator and never counts allocated cost again as cash spend. Record cache hits/misses and actual provider usage/charges where available; do not invent a percentage saving or treat reused output as a fresh model trial. Reading the reused context can still incur input-token cost; artifact reuse removes regeneration, not necessarily all inference charges.

Initial acceptance plan (completed in bounded form by the result section): inventory existing source-only artifacts, finish each calibration project's missing onboarding once, and freeze its manifest. Before scaling, demonstrate that a second isolated clone needs no new onboarding LLM generation, produces the same common artifact hashes, and binds navigation to its own source. Exercise relevant-file and rules-only changes, plus rejection of incompatible/future/task-derived artifacts. Verify writes in one clone cannot alter another. These were the initial prospective checks. The result section records what was actually demonstrated; full native admission remains unqualified.

## Decision and scope

**Decision:** restore the normal environment as a common baseline before evaluating effort or Recon.

**Context:** restricted file-tool experiments omitted deployment-critical context and capabilities.

**Alternatives considered:** adding still more prompt text leaves missing infrastructure; directly exposing the host Codescout server risks shared state/outcome access; container-local pinned runtime preserves isolation but requires compatibility qualification.

**Consequences:** closer operational relevance and equal environments; more setup/LSP/index/runtime cost which must be measured. Candidate method remains unvalidated.

**Change scenarios absorbed:** switching task repositories, repeating low/high arms without shared memories, upgrading Codescout while retaining historical reproducibility.

**Revisit-when:** runtime packaging fails full MCP/LSP validation or new capabilities change the isolation boundary.

**Confidence:** high on required target correction; medium on container runtime approach until full qualification.

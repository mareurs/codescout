Plain-low removed the panic with NAME_REF/INT_NUMBER and omitted the required parse error. On bindgen, both lows added an Alias-kind condition but did not follow type references before checking it. Xhigh used through_type_refs and passed both ordinary-original and hidden-newtype behavior. Neither causal call supplied the requested complete diagnosis before the first production edit: RA's full DIAGNOSIS appeared after its edit; bindgen had only a short search comment before the edit and a post-edit explanation. Literal audit predicate (DIAGNOSIS in text before any Write/Edit) is explicitly separate from semantic/manual trajectory inspection. No run was filtered or rerun for non-adherence.

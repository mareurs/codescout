## Review focus

1. Actor source accidentally assigned the reference path, or private fixture marker passed in public metadata, must fail before any provider call; a clean checksum alone does not prove the right role.
2. Implementation-only or single-helper reference cannot masquerade as the complete original test_patch closure; constructor and consumer require both original patch hashes and exact reference bytes.
3. Reference patch application may create/delete files or alter modes/links. Protect the original baseline and include empty directories/untracked content; unsupported/escaping aliases fail closed.
4. A result with complete/resource_valid but exit101, missing one command, duplicate receipt, changed source or replaced generated dependency bytes cannot qualify a reference.
5. A current code or original record change cannot silently rebind a historical control. Bind immutable preparation versions, retain every failure and observe mutants before adding any regression that closes them.

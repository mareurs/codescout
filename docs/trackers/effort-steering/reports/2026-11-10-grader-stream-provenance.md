## Mechanism and next bounded change

multilang_control.py retains only the last4096bytes of each test/rebuild command's merged output; the separate print commands provide the parser log. A test command that redirects nextest stdout to a JSON file therefore supplies stderr as an independent tail. grade_policy.contextual_step_output cannot recover its enclosing section by matching it against the unrelated JSON log. Increasing the set of recognized headers cannot reconstruct a discarded header or section boundary.

Revisit the capture contract before another classifier patch: retain separate complete command/print streams within an explicit byte limit, names/order, exact bytes or an unambiguous decoding contract, completeness flags and hashes. Tails remain display data. Register and measure the runner version/format; ambiguous or incomplete provenance must not silently award pass or be selectively discarded. Then qualify the format-specific extraction using actual long captures and injected top-level faults, cut ANSI/UTF-8, multiple print streams, nested output and the review's guard mutations. Complete streams solve the observed information loss; they alone do not prove arbitrary test text cannot mimic a human-output delimiter. That framing trust boundary needs a measured contract too.

F3's missing-status/deletion/abort policy is unchanged and remains an operator decision. F6/F7 are not silently resolved here.

# Baseline-first oracle design

## Intent and authority

Find a generic mechanism that helps low repairs at lower complete-workflow cost. The operator explicitly delegates experiment design/execution and a standing USD 200 series; no merge or push. This is a small resident development experiment using the already qualified isolated adapter worktree, not a product feature. Design/implementation choices here are the executor's under that delegation; no new operator approval is claimed.

## Evidence and approaches

The semantic-contract prompt already asked for producer tracing, a failure and nearest legitimate case, precise assertions and pre-edit execution; that treatment gave no measured quality gain. A blind verifier that saw the wrong proposal, then another that also saw expectation-free baseline/proposal observations, both generated a mixed-stream no-error assertion that accepts wrong fixes and rejects the qualified reference. Latest audit: wrong proposals rejected 0/1, reference retained false, USD 0.2566531. These are exposed development controls on one task.

More repeats of that protocol do not address oracle independence. Higher effort on an unchanged candidate-visible verifier could test effort but retains the same anchoring opportunity. Chosen approach: remove candidate access altogether during contract/test authorship, with a fixed low/xhigh pair on the same narrow oracle-author task. This compares possible focused escalation without rerunning full repairs. It does not identify candidate visibility causally because the packet/prompt differ from the earlier control.

## Mechanism and boundaries

Each author gets the public issue, pristine baseline source/image, independently cloned existing source-only onboarding, and the same project/global rules, tools, pinned skill plugin and CLI. No proposal patch/image/diff, differential observation packet, previous generated tests/transcript, private witness/test patch, reference, outcome labels or controller diagnosis. The host evaluates saved wrong and reference patches only AFTER BOTH outputs are closed and frozen. Each author has a separate writable snapshot and one-shot markers. The actual contract-first boundary is enforced by image/mount/prompt bindings, rather than trusting a request to ignore an accessible candidate.

Authors write oracle_contract.json with independently justified requirement, preservation or unresolved clauses, public source citations and declared executable contrast_ tests. They may abstain. No production/configuration/existing-test changes are admitted. Existing module registration can add a new test module. Baseline-pass alone is not truth: intentional bug behavior must change. No task-specific private example or error representation is inserted into the generic protocol.

## Fixed pair and measurement

Exactly one low then one xhigh Sonnet 5.5 author, same public inputs/protocol, pinned CLI 2.1.309, max eight continuations, native hard 32 GiB/4 CPU/network none/executable 4 GiB tmpfs, qualified process-local legacy negotiation/capture. Native launch floor 24 GiB host for three samples; continuous floor 16 GiB at two seconds. Same qualified adapter/source gate reused, no product source edits or repeated onboarding LLM calls. Offline evaluator: 4 CPU/8 GiB native limit and 24 GiB host floor. Resource failures are infrastructure-invalid; keep costs and stop without resampling. No automatic paid retry.

Freeze both complete outputs and declared test sets before any reference/private access. Execute each frozen test patch on baseline, saved wrong proposal and qualified reference. Report named outcomes by clause and compile/resource/cleanup validity. A usable oracle must preserve the qualified reference, reject the saved wrong proposal via a justified preservation clause, and include a justified requirement assertion distinguishing baseline from reference. An abstention, unsupported expectation, reference rejection or acceptance of the wrong proposal is not a usable detector. The private source-known controller does not score justifications as blinded; actual matrix is the primary development endpoint.

## Budget, reuse and stop

Prior known model cost USD 62.410596299999999054; original pre-provider startup attempt retains an unresolved USD 4 hold. New fixed pair reserves USD 4 per author, CLI cap USD 3 each, under the standing USD 200 series. Reconcile final cumulative cost once per author and preserve known cost if later capture/audit fails. No additional full repair run or transfer cohort until this screen succeeds. Even a successful pair is one exposed development task; fresh outcome-blind transfer and complete-workflow cost remain necessary.

## Deliverables

One bounded resident runner/preparer using unchanged qualified adapter source; binding/visibility fixtures and actually applied mutation checks on the new barrier; two frozen outputs or explicit abstentions; raw named test matrix, runtime/cleanup/cost audit; result report with a go/no-go decision. Never fold the known private mixed witness into an author prompt. Existing cohorts, pending grader paths, original invalid attempts and peer work stay unchanged.
